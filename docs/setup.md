# Choose a starter setup

Begin with one real task and a way to check its output. Coding experience is not required to follow the course; the GUI-only walkthrough is still to be prepared.

## Working notes

- Write down the question, expected artifact and stopping condition.
- Keep a brief and results log outside the conversation.
- Choose an environment that fits the experiment’s lifetime.

## Quick starts

=== "Laptop"

    1. Create a disposable working folder with a short task brief.
    2. Open your chosen agent interface and give it a small, checkable task.
