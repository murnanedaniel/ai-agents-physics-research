# A bounded delegation contract

Delegate a verifiable unit of work with a precise hand-back.

## Working notes

- Specify editable files and forbidden changes.
- Name the verification command and required artifacts.
- Make deviations visible in the final report.
- Keep shared-state decisions and permission boundaries explicit.

Source: course evidence synthesis, §3–4. These are selected observations, not general performance guarantees.
