# Hands-on exercises

All three exercises from the course, in the order we do them. Each one takes 5 to 10 minutes and works in a web chat (claude.ai, ChatGPT, or a phone), in a terminal agent such as Claude Code or Codex, or on your own project.

| # | Exercise | What you leave with |
|---|---|---|
| 1 | [Interview your research setup](setup-interview.md) | A short rules file and one starter skill (or a block of chat instructions) |
| 2 | [Review a draft, then audit its claims](review-a-draft.md) | A three-view review and a verdict on every claim, with its source |
| 3 | [Turn a rule into a check that can fail](gates-and-checks.md) | One rule as a test or hook, seen failing and then passing |

New to agents? Start with exercise 1 in a web chat. It needs nothing installed.

The skill behind exercise 1 is at [skills/research-setup](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills/research-setup). For the slides, see the [deck](../../).
