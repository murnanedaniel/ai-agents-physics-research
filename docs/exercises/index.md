# Hands-on exercises

Four hands-ons, one per loop, in the order we do them. Each ends with a [show and tell](show-and-tell.md): a short pull request to the course repository that appears on the live wall in the deck. Every card has a web-chat tier (claude.ai, ChatGPT, or a phone), a terminal-agent tier such as Claude Code, and an own-project tier.

| # | Loop | Exercise | What you leave with |
|---|---|---|---|
| 0 | Setup | [Get set up](hands-on-0-setup.md) | GitHub account, Claude Code and the course skills, a `CLAUDE.md` and memory notes, your first PR |
| 1 | Inner | [What could your project hill-climb?](hands-on-1-hill-climb.md) | A one-page `HYPOTHESIS.md`: question, metric, held-out check, overnight loop |
| 2 | Middle | [What have you been putting off?](hands-on-2-putting-off.md) | One real task drafted by Claude in Chrome, submitted by you |
| 3 | Outer | [What dashboard would fit your research?](hands-on-3-dashboard.md) | A local research dashboard and 30 minutes of agent work on it |

How to share after each one: [Show and tell](show-and-tell.md).

## Parts and stretch

| Used in | Exercise | What you leave with |
|---|---|---|
| Hands-on 0 | [Interview your research setup](setup-interview.md) | A short rules file and one starter skill (or a block of chat instructions) |
| Hands-on 1 stretch | [Turn a rule into a check that can fail](gates-and-checks.md) | One rule as a test or hook, seen failing and then passing |
| Hands-on 2 stretch | [Review a draft, then audit its claims](review-a-draft.md) | A three-view review and a verdict on every claim, with its source |

New to agents? Start hands-on 0 in a web chat. It needs nothing installed.

The course skills are in [skills/](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills). Each hands-on has one, started by asking in plain words: [research-setup](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills/research-setup) ("interview me about my research setup"), [hill-climb-plan](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills/hill-climb-plan) ("help me pick what to hill-climb in my research"), [put-off-task](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills/put-off-task) ("help me with a task I've been putting off") and [research-dashboard](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills/research-dashboard) ("build me a dashboard for my research"). [share-to-course](https://github.com/murnanedaniel/ai-agents-physics-research/tree/main/skills/share-to-course) opens your show-and-tell PR. For the slides, see the [deck](../../).
