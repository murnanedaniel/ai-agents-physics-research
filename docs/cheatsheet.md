# Monday’s checklist

Start with one experiment and a known result. Expand only when the evidence supports it.

## Working notes

- Write the hypothesis and a bounded delegation contract.
- Reproduce the baseline, then change one thing.
- Check artifacts and negative controls; investigate surprising metrics.
- Keep provenance, review findings and decisions in durable files.
- Agree resource budgets and approval gates before long runs.
- At hand-back, tally verified, unsupported, failed and pending claims.

Source: course evidence synthesis, §3–4. These are selected observations, not general performance guarantees.
