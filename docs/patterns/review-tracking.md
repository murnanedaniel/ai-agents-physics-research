# Carry review findings into the next draft

A review is unfinished until its findings have a recorded disposition.

## Working notes

- Assign each finding a stable identifier.
- Record the proposed fix and the artifact that implements it.
- Verify the fix against the original concern.
- Retain unresolved findings across drafts instead of rewriting the project history.

Source: course evidence synthesis, §2.3, §5. These are selected observations, not general performance guarantees.
