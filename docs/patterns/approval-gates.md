# Approval gates

Agree which actions need a human decision before delegating a long task.

## Working notes

- Production-data incidents led to durable restrictions on destructive actions.
- Expensive studies need an agreed configuration and resource budget.
- A delegated agent cannot create user authority by relaying a message.
- Persist approval boundaries in enforceable settings and guards.

Source: course evidence synthesis, §3, §6. These are selected observations, not general performance guarantees.
