# Exit zero is not evidence

Verify the scientific artifact, not just the process status.

## Working notes

- A successful stage reported completion while processing zero events.
- An evaluator ran on a partially written file when existence was treated as completion.
- Growing logs and active scheduler jobs do not prove scientific progress.
- Validate output counts, completeness and meaning; include a failing control.

Source: course evidence synthesis, §2.7, §4. These are selected observations, not general performance guarantees.
